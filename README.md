# TruthChain: AI-Powered Fake News Detection
Developed for **CityU FusionX Hackathon 2026**.

## 🚀 Key Features
- **AI Classification**: Uses a PassiveAggressive Classifier with **93.58% accuracy**.
- **Transparent Verification**: Designed to store verification hashes on the **Blockchain** for tamper-proof results.
- **Fast & Scalable**: Optimized for real-time news analysis.

## 📊 Dataset Note
Due to the file size limit (30MB), the dataset `news_datasets.csv` is not included in this repository.
## 🛠 Tech Stack
Python (Pandas, Scikit-learn), Canva (Prototype).
